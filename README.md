# Smart Block — website

Static site for the Smart Block Chrome extension, served by GitHub Pages:
<https://ismoilovmk.github.io/smart-block/>

Pages are generated by `python build.py`. Pass the path to the extension's
`PRIVACY.md` to refresh the privacy pages:

```
python build.py ../smart_block_code/PRIVACY.md
```

Problems with the extension: open an issue here.
